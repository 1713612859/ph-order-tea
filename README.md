# ChaTea 项目逻辑与原型说明

## 定位与启动
菲律宾茶饮自提移动端原型，React 18 + TypeScript + Vite + Tailwind + Zustand，支持中英切换及 PWA。运行 `npm install`、`npm run dev`，生产检查 `npm run build`。

当前采用 480px 移动端容器，桌面居中展示。未提供独立设计稿，本轮以现有 ChaTea 品牌为基础建立抹茶绿、奶油白与衬线标题的视觉方向。杯身使用本地矢量插画，后续可通过 Product.image.url 替换真实商品摄影。

## 页面与主链路

| 页面 | 职责与去向 |
| --- | --- |
| / | 品牌展示、自提入口、会员入口；已有门店进入菜单，否则先选店 |
| /stores | 附近/收藏门店、搜索；更换门店且有商品时确认清空购物袋 |
| /menu | 按分类展示门店商品与售罄状态；饮品进入规格页，周边可直接加购 |
| /product/:id | 基础规格、糖度、温度、换奶、加料、数量、备注；支持 line 参数编辑 |
| /cart | 商品选择、数量及配置编辑，仅结算勾选项 |
| /checkout | 登录、取餐时间、打包费、优惠券、费用明细；生成订单快照并移除已下单项 |
| /payment/:orderId | 模拟支付成功、失败和取消；失败可重试 |
| /orders 与 /orders/:id | 订单列表、取餐码、订单详情及演示状态推进 |
| /me | 会员资料、积分与会员相关入口 |

## 业务规则

- 单门店购物袋：商品 + 排序后的规格选项 + 备注一致时合并数量。
- 金额使用整数 centavos；基础规格价格 + 加价选项得到单价，再乘数量。
- 已登录且会员价开关开启时使用可用会员价格。
- 实付 = 商品小计 + 打包费 - 优惠券折扣；VAT 从含税总额拆分，不再额外叠加。
- 下单时保存名称、规格、数量、价格和门店快照，后续展示不依赖购物袋。
- 订单状态：pending_payment → paid → making → ready → completed。
- 失败/取消的支付尝试保留记录，订单仍待支付；已支付订单不能重复写入支付结果。
- 预约取餐时间写入预计完成时间，即时取餐按门店预计制作时间计算。

## 代码分层

- src/features：页面与页面交互。
- src/components：布局、弹层、按钮辅助组件及 TeaArtwork 商品插画。
- src/stores：设置、登录、购物袋、订单的 Zustand 状态，localStorage 持久化。
- src/lib/repositories：门店、商品和优惠券数据读取入口，目前为同步模拟仓储。
- src/lib/pricing.ts：计价、优惠和含税拆分。
- src/lib/order.ts：订单快照与状态顺序。
- src/data 与 src/types：模拟业务数据及领域类型。

## 本轮改动

首页品牌头部、抹茶主视觉、自提卡片、会员权益及新品发现区；统一页面色彩、边框、按钮、焦点与底部导航。商品占位杯图改为带品牌标签的可缩放插画。菜单分类栏吸顶，分类定位避让头部，购物袋栏避让底部导航。移除首页 Story 跳转个人中心等不对应的快捷入口。

修复登录后结算回调读取旧登录状态及旧会员价格的问题；补充商品提交的门店和售罄/必选校验；阻止已支付订单再次记账；预约订单预计时间与用户选择一致。

## 原型边界与后续接入

目前没有后端：登录不校验短信，支付不调用真实渠道，距离和制作队列是模拟值，订单仅保存在当前浏览器。配送尚未开放。优惠券仅实现原型门槛与折扣计算，正式上线还需要有效期、归属、门店/商品适用范围和核销校验。真实库存、支付回调、服务端幂等、取餐时段/营业时间与订单归属权限需要由后端保障。

## 验证

生产构建和 TypeScript 检查；浏览器首页视觉检查，以及首页进入选店、选店进入菜单的交互检查。完整支付及所有异常分支仍需进一步回归。

加购权限：游客可以浏览商品与选择规格；菜单加号、详情加购及立即下单均需登录，未登录点击将打开登录弹层且不修改购物袋。登录后需再次点击加购。状态层同样拦截游客新增、编辑和增加已有商品数量。
